# Bandes Rythmo Studio - Client-side Editor

Overview
- Ocean Professional themed React SPA
- Client-only processing, zero uploads
- Multi-format video via HTML5 video element
- 60 FPS canvas preview overlay
- Interactive timeline: drag to create chunks
- Bandes list: quick text edits
- Character manager: add/remove with color
- Import SRT / VTT, Export SRT

Quickstart
1. npm install
2. npm start
3. Open a local video (Open Video button)
4. Import subtitles (SRT/VTT) or add new lines
5. Edit, sync on timeline, preview on canvas
6. Export as .srt

Shortcuts
- Space: Play/Pause
- ← / →: Seek -100ms / +100ms
- I: Import modal
- E: Export modal

Notes
- All features run locally in the browser.
- Recommended Chrome or Edge for best performance.
